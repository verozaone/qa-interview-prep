# 🧪 Test Types in QA

## Manual Testing
Testing done manually without any automation. Best for exploratory and usability testing.

## Automation Testing
Scripts written using tools like Selenium, Playwright, or Postman to automate repetitive test cases.

## Regression Testing
Ensures that new changes haven’t broken existing features.

## Smoke Testing
Basic checks to verify the core functionality of the app.

## Integration Testing
Verifies interactions between modules or services.

## System Testing
Validates the complete system against the requirements.

## UAT (User Acceptance Testing)
Performed by the client to validate business needs before release.
