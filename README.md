# 📚 QA Interview Prep

This repository contains curated notes, tips, and short references to help prepare for QA interviews. It covers both manual and automation testing concepts, tools, and soft skills needed to succeed in real-world QA roles.

## 📁 Folder Structure

| File | Description |
|------|-------------|
| `test-types.md` | Manual, Automation, Regression, Smoke, UAT explained |
| `test-design-techniques.md` | Equivalence Partitioning, BVA, State Transition |
| `bug-life-cycle.md` | Bug tracking workflow with examples |
| `agile-scrum-notes.md` | Sprint, standup, planning, velocity, ceremonies |
| `tools-and-commands.md` | Postman, Git, Maven, Jenkins cheat sheet |
| `java-for-testers.md` | Core Java concepts often asked in interviews |
| `sample-qa-questions.md` | Frequently asked interview questions & answers |
| `visual-diagrams/` | Diagrams for SDLC, STLC, bug lifecycle, CI/CD |

---

### 🚀 How to Use

- Browse the markdown files as quick notes.
- Use for last-minute interview prep or during study.
- Keep adding your own notes as you learn new things.
